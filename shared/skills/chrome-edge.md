# Chrome / Edge
- The three-dot menu (top-right) holds Settings, History, Downloads, Extensions, Print and Zoom.
- Ctrl+L focuses the address bar; Ctrl+T new tab; Ctrl+Shift+T reopens a closed tab.
- Site settings (camera, mic, notifications) are behind the icon at the left of the address bar.
- When the question is about the page itself, point at the page content, not the browser chrome.
