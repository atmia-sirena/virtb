# Excel
- The ribbon tabs: Home (formatting, sort and filter), Insert (charts, pivot tables), Formulas, Data (text to columns, remove duplicates), Review, View (freeze panes).
- The formula bar sits under the ribbon; the Name Box at its left shows the selected cell.
- Filters: select the header row, then Data > Filter. Freeze the header: View > Freeze Panes > Freeze Top Row.
- XLOOKUP beats VLOOKUP for lookups; explain formulas one argument at a time.
