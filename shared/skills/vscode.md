# VS Code
- The activity bar on the far left switches Explorer, Search, Source Control, Run and Debug, Extensions.
- Ctrl+Shift+P opens the Command Palette, the fastest route to any command; Ctrl+P opens files by name.
- The integrated terminal is toggled with Ctrl+`; problems and output share the bottom panel.
- Source Control: stage with the + next to a file, type a message, then Commit.
- Errors show as red squiggles; hovering shows the message, Ctrl+. offers quick fixes.
