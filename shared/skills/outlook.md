# Outlook
- New mail is top-left. Reply, Reply all and Forward sit above the reading pane.
- Rules: Settings (gear) > Mail > Rules in new Outlook; File > Manage Rules & Alerts in classic.
- Focused/Other tabs sit above the message list; Sweep and Archive help clean up.
- Never press Send on the user's behalf in a walkthrough; point at it and let them click.
