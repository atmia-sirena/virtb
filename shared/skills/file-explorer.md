# File Explorer
- The address bar at the top accepts paths; the search box at its right searches the current folder.
- "New" (top-left of the command bar) creates folders and files. The "..." menu holds less common commands.
- View > Show > File name extensions and Hidden items are the usual fixes for "I can't see the file type".
- Right-click > Show more options reveals the classic context menu (7-Zip, Git, etc.).
- The left navigation pane holds Home, Gallery, OneDrive, This PC and pinned folders.
